# GPT-Analyze2

A macOS SwiftUI app for analyzing GPT conversation exports. A restart of `GPT-Analyze` with the same structure.

## What's here

- `GPT_Analyze2/` — the app sources.
- `GPT_Analyze2.xcodeproj` — Xcode project; open and run.
- `EFFICIENCY_REPORT.md`, `SWARM_ANALYSIS_REPORT.md` — generated assessments, not documentation of the code.

## Status

Seven commits, December 2025, then stopped. Of the two versions this is the later one, so start here rather than in `GPT-Analyze` — but neither got past the initial build. The working conversation-analysis code is in `conversation-analysis-tools`.
